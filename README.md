# 📊 Corporate Spend Analysis — Power BI

## 📌 Project Overview

**Corporate Spend Analysis** is an interactive Power BI business intelligence project developed to analyze corporate and IT expenditure, compare **actual spending with planned budgets**, and identify key spending trends and variances.

The dashboard provides management with a centralized view of spending performance across different **business areas, IT areas, countries, regions, and time periods**.

---

## 🎯 Business Objectives

* Monitor overall corporate and IT spending.
* Compare **Actual Spend vs. Planned Spend**.
* Identify significant budget overruns and underspending.
* Analyze spending trends over different time periods.
* Identify high-spending business and IT areas.
* Compare spending performance across regions and countries.
* Provide interactive reporting for management decision-making.
* Enable users to drill down from summary-level KPIs to detailed analysis.

---

## 🧩 Data Modeling

The project uses a structured data model containing:

* **Fact Spend Table**
* **Date Dimension**
* **Country/Region Dimension**
* **Business Area Dimension**
* **IT Area Dimension**
* **IT Sub-Area Dimension**

Relationships were created between fact and dimension tables to support efficient filtering and analysis.

---

## 🧮 DAX & KPIs

Key measures were created using DAX, including:

* **Actual Spend**
* **Planned Spend**
* **Plan Variance**
* **Plan Variance %**
* **LE1 Variance %**
* **LE2 Variance %**
* **LE3 Variance %**

These measures allow users to dynamically analyze spending performance based on selected filters.

## 📊 Corporate Spend Analysis | Power BI

An interactive **Power BI dashboard** developed to analyze corporate and IT spending, compare actual expenditure against planned budgets, and identify key spending trends and variances.

### 🔍 Key Features

* 📈 Actual vs. Planned Spend analysis
* 💰 Plan Variance and Variance % KPIs
* 🌍 Regional and country-level spend analysis
* 🏢 Business Area and IT Area analysis
* 📅 Year-wise spending trends
* 🎯 Interactive slicers, filters, and drill-downs
* 📊 KPI cards, charts, maps, matrices, and decomposition tree
* 🧮 DAX measures for dynamic calculations
* 🔄 Data cleaning and transformation using Power Query

### 🛠️ Technologies Used

**Power BI | Power Query | DAX | Data Modeling**

### 🎯 Business Objective

The dashboard enables stakeholders to monitor spending performance, identify significant budget deviations, understand spending patterns, and make **data-driven financial decisions**.

### 📌 Project Outcome

A user-friendly and interactive reporting solution that provides both **high-level KPI monitoring and detailed spend analysis** across different business, IT, and geographical dimensions.
